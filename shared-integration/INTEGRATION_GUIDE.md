# Pre-K–12 Family Registry Integration

Add the following two scripts near the end of each Khaemenes school root page, before `</body>`.

## Preschool / Crechè

```html
<script src="https://vervenveda.com/Khaemenes_Academy.github.io/assets/khaemenes-family-registry.js"></script>
<script
  src="https://vervenveda.com/Khaemenes_Academy.github.io/assets/khaemenes-family-school-bridge.js"
  data-khaemenes-stage="preschool"></script>
```
