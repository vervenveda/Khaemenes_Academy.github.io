Curriculum & Electives by Subject

Browse core subjects, health and PE, languages, creative studies, specialist courses and independent learning across the Verve N Veda ecosystem. This replaces the single Art 101 promotion with a broader, source-linked inventory.

Curriculum status matters. Course = existing instructional pathway; Partial course = lessons still being developed; Workshop = focused instructional application; Course catalog / Outline = planned learning sequence; Resource / Tool = enrichment, not an assessable class. These labels describe source evidence, not accreditation or automatic credit. A verified Academy learner and appropriate placement remain required for official records.
